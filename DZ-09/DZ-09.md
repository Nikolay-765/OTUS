# ДЗ № 9
## Тема: BASH
Задание: \
Написать скрипт bash-скрипт для CRON, который раз в час формирует отчёт о работе веб-сервера и отправляет его на заданную почту. \
Отчёт должен содержать:
  - IP-адреса с наибольшим числом запросов (с момента последнего запуска);
  - Запрашиваемые URL с наибольшим числом запросов (с момента последнего запуска);
  - Ошибки веб-сервера/приложения (с момента последнего запуска);
  - HTTP-коды ответов с указанием их количества (с момента последнего запуска).
Скрипт должен предотвращать одновременный запуск нескольких копий, до его завершения.
В письме должен быть прописан обрабатываемый временной диапазон.
## Выполнение задания
Для отправки email будем испорльзовать утилиту mutt \
Устанавливаем ее на VM
```
root@server:/# apt update
root@server:/# apt upgrade
root@server:/# apt install mutt
```
Настраиваем работу mutt под SMTP сервер mail.ru (создаем/редактируем конфигурационный файл ~/.muttrc)
```
set realname = "Nikolay"
set from = "test@mail.ru"

set smtp_url = "smtps://test@mail.ru@smtp.mail.ru:465/"
set smtp_pass = "******************"

set ssl_force_tls = yes
set ssl_starttls = yes
```
Пишем скрипт и отлаживаем его работу \
В результата полулся [report.sh](/DZ-09/Script/report.sh)
