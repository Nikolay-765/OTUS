# ДЗ № 20
## Тема: "Настройка PXE сервера"
Задание: 
Настроить загрузку по сети дистрибутива Ubuntu 24
- Установка должна проходить из HTTP-репозитория.
- Настроить автоматическую установку c помощью файла user-data
- Задания со звёздочкой - Настроить автоматическую загрузку по сети дистрибутива Ubuntu 24 c использованием UEFI

## Выполнение задания
Подготовлены:
1. [Vagrant](./Files/Vagrantfile) - конфигурационный файл Vagrant, поднимает две VM ОС Ubuntu 24.04
- pxe-server (IP: 192.168.60.150)
- client (IP: 192.168.60.160) \
обе VM вторыми интерфейсами смотряю в private network: internal (192.169.60.0/24), через нее и будет установливаться \
на VM client по сети новая ОС Ubuntu 24.04.4 live server (c использованием загрузчика UEFI)

2. [pxe-server.yml](./Files/pxe-server.yml) - сценарий Ansible для предварительной настройки VM pxe-server, долже лежать в ./Provisioning \
относительно Vagrant, обновляет ПО, устанавливает пакеты: dnsmasq и apache2

4. [PXE_serv_conf.sh](./Files/PXE_serv_conf.sh) - bash скрипт для окончательной настройки VM pxe-server, запускается автоматом при провиженге, \
должен лежать в ./Script относительно Vagrant, качает ubuntu-24.04.4-netboot-amd64.tar.gz и ubuntu-24.04.4-live-server-amd64.iso, \
настраивает TFTP и HTTP сервера, в том числе формирует файл user-data для автоматической настройки раскатываемой ОС.

Важный момент, после запуска vagrant сначала автоматом поднимется и полностью настроится VM pxe-server. \
Затем будет создана VM client, но ОС на ней не стартанет. Нужно руками через VBox ее выключить и обязательно отключить в ней первый интерфейс.
После этого ее можно запускать. Следует только в boot manager выбрать PXEv4 загрузку. Дальше система автоматом установится по сети с PXE сервера. 
При этом будет использоваться UEF bootloader - bootx64.efi и т.д. \
Креды от новой установленной по сети ОС будут poweruser:poweruser

PXE server для установки ОС Ubuntu 24.04.4 live server (c использованием загрузчика UEFI) работает.
